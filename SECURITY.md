# Security Policy

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

Please **do not** open a public issue for security problems (for example XSS in the HTML
or block-rendering helpers). Use GitHub's
[private vulnerability reporting](https://github.com/numankhan4/wp-headless-kit/security/advisories/new)
instead. You'll get a response within a few days, and a fix and advisory will be published
once the issue is confirmed.
