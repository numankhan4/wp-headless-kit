# Roadmap

The backlog lives in GitHub Issues labeled `roadmap`. This file sets the direction the weekly planner follows.

1. **Foundation**: lockfile, linting, formatting, coverage, changelog.
2. **Client**: pagination iterator, retries, timeouts, auth, custom post types, search, menus, caching, WPGraphQL.
3. **SEO**: JSON-LD, sitemaps, RSS, Rank Math, breadcrumbs, robots.
4. **Blocks**: built-in safe renderers (image, embed, gallery), table of contents, sanitizer, link/image rewriting.
5. **Next.js adapter**: revalidation webhook, draft preview, `generateStaticParams`, React block renderer, example app.
6. **Docs & quality**: API reference, guides, edge-case tests, benchmarks.

Non-goals: a WordPress plugin, a UI kit, or runtime dependencies in the core.
